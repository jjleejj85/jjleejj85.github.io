OpenCode

OpenCode 是一个开源的 AI Coding Agent，可以通过终端、桌面应用或 IDE 使用。它能够进入真实项目，读取代码、修改文件、运行命令，并根据你的反馈继续迭代。

第一次 Vibe Coding

Vibe Coding 不是"一句话生成完美软件"，而是一个不断沟通、判断和修改的迭代过程。

1 有一个想法
→
2 告诉 OpenCode
→
3 看看它做出来什么
→
4 发现不满意的地方
↻

继续告诉它怎么改，再看看，不满意就再来——循环下去，而不是一次到位。

一个完整的例子：从课程大纲生成课程介绍 PPT

下面看看 Agent 是怎么一步步完成这个真实任务的。

  1. 1

    添加一个新的项目

    在 OpenCode 里新建一个项目，作为这次任务的起点。

  2. 2

    选择带有课程大纲 PDF 的文件夹

    让 Agent 看到文件夹里已有的《计算机科学导论》课程大纲。

  3. 3

    描述 Prompt

    告诉它你要做什么。下面是这次用到的 Prompt，可以复制：

    参考 Prompt 
    请根据附件中的《计算机科学导论》课程大纲，帮我制作一个面向本科新生的课程介绍 PPT。

目标：
让学生在第一次上课时快速了解这门课程，包括课程是什么、会学什么、如何考核、如何参与课程。

请根据大纲内容提炼信息，不要简单复制 PDF。

PPT 风格希望：
- 简洁、现代、适合课堂展示
- 不要像传统教学大纲一样堆文字
- 尽量使用清晰的结构、图示和视觉化表达

内容可以包括：
1. 课程简介：这门课是什么，为什么学习计算机科学
2. 课程主要内容：展示从计算机基础到人工智能、前沿应用的发展路线
3. 课程安排概览
4. 课程考核方式
5. 小组项目和课程参与方式
6. 结束页：鼓励学生探索计算机科学

请直接生成一个完整的 PPT 文件。

如果需要做设计取舍，请优先保证：
信息清楚 > 视觉美观 > 内容丰富。

完成后告诉我生成了哪些文件。
  4. 4

    Agent 开始工作

    和普通的对话大模型不一样，Agent 可以直接访问工作路径下的文件并修改，也可以生成新的文件。

  5. 5

    Agent 完成工作

    它会读取大纲、提炼信息，然后生成并输出完整的 PPT 文件。

  6. 6

    生成结果审阅

    打开生成的 PPT 看看效果，不满意就继续告诉它怎么改。

Your Turn / Resources

到这里，课堂的主要内容就结束了。剩下的很简单：真正打开 OpenCode，亲手试一次。

  1. 1 找一个自己真的想做的小东西
  2. 2 建一个空文件夹，用 OpenCode 打开它
  3. 3 告诉它你想做什么

怎么描述，看你的需要

  • 已有明确想法，就把目标、内容、风格、限制等要求说得详细一些。
  • 只是想先试试，从一句简单的话开始也没问题。
  • 看到结果之后，再根据自己的想法继续告诉它怎么调整。

一个帮你迈出第一步的例子（不是万能模板）

我想做一个 ______。先帮我做一个可以运行的第一版。
