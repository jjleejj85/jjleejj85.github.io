OpenCode

OpenCode 是一个开源的 AI Coding Agent，可以通过终端、桌面应用或 IDE 使用。它能够进入真实项目，读取代码、修改文件、运行命令，并根据你的反馈继续迭代。

第一次 Vibe Coding

Vibe Coding 不是"一句话生成完美软件"，而是一个不断沟通、判断和修改的迭代过程。

1 有一个想法
→
2 告诉 OpenCode
→
3 看看它做出来什么
→
4 发现不满意的地方
↻

继续告诉它怎么改，再看看，不满意就再来——循环下去，而不是一次到位。

举个例子：Prompt 没有固定写法

有明确想法时，可以描述得细一点：

  • 你做一个介绍我家乡的小网页：深色背景，分历史、美食、交通三块内容，标题简洁，手机上看也要舒服
  • Agent按这些要求创建文件，完成第一版……

只是想微调时，简单说一句就够了：

  • 你帮我做一个介绍我家乡的小网页
  • Agent创建文件，做出第一版……
  • 你有点太普通了
  • Agent重新调整设计……
  • 你手机上太挤了
  • Agent优化移动端布局……
  • 你标题再简洁一点
  • Agent修改标题……

Prompt 没有固定的长度和写法：想法清楚，就描述得细一些；只想微调，一句话就够了。关键不是"写得短"，而是把自己真正想要的表达清楚。
