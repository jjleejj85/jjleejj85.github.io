OpenCode

OpenCode 是一个开源的 AI Coding Agent，可以通过终端、桌面应用或 IDE 使用。它能够进入真实项目，读取代码、修改文件、运行命令，并根据你的反馈继续迭代。

安装 OpenCode

方式
系统

macOS 可以从 OpenCode 官方下载页面获取桌面版安装包，也可以用 Homebrew 一键安装。

brew install --cask opencode-desktop
OpenCode 官方下载页面 →

Windows 可以到 OpenCode 官方下载页面直接获取桌面版安装包。

OpenCode 官方下载页面 →

Linux 可以到 OpenCode 官方下载页面获取 .deb 或 .rpm 桌面版安装包。

OpenCode 官方下载页面 →

macOS / Linux 可以使用官方安装脚本，一行命令即可装好 CLI。

curl -fsSL https://opencode.ai/install | bash
OpenCode 官方下载页面 →

OpenCode 可以直接在 Windows 上运行，但官方推荐使用 WSL 以获得更好的体验，再在 WSL 内安装 OpenCode CLI。

curl -fsSL https://opencode.ai/install | bash
OpenCode 官方下载页面 →

macOS / Linux 可以使用官方安装脚本，一行命令即可装好 CLI。

curl -fsSL https://opencode.ai/install | bash
OpenCode 官方下载页面 →

提示：npm、Bun、Chocolatey、Scoop 等其他安装方式这里不逐一展开，需要时可以直接去官方安装页面查看。

查看官方安装页面 →
